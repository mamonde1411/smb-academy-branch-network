# smb-academy-branch-network
Network design for a two-site language academy — role-based segmentation and access control, built from the owner's real operational requirements.

# 프로젝트 개요
이전에 일하던 영어 도서관 겸 어학원에서 운영자의 고충을 들어 프로젝트를 시작하게 됐다. 운영자는 학원에서 쓰이는 모든 자료(학생 정보, 결제 내역, 수업 자료, 도서 DB, 스케쥴 등)가 한 구글 드라이브에 저장되어 있고 모든 직원들이 그 어카운트를 사용하는 것에 불안함을 느꼈다. 실제로 과거 퇴사자가 모든 자료가 삭제한 사고도 있었다. 구글 본사에 전화해 일부 복구가 가능했지만 금전적인 손해를 입었다. 운영자는 학원 운영 프로그램(학생 관리, 도서·수업 자료 관리, 결제)을 자체적으로 두고 싶어했고 직원들이 직분에 따른 엑세스 권한을 가지길 원한다. 1~2년 내 지점을 열 예정이며 그때는 구글 드라이브 대신 자체 인프라로 운영하길 원한다.

# 요구 사항
| # | 요구사항 (고객 언어 그대로) | 출처 |
|---|---|---|
| 1 | 직무별로 볼 수 있는 자료의 범위를 나눌 것 (프론트데스크 / 강사 / 도서관리 / 수업 자료 제작팀)
| 2 | 한 사람이 전체 자료를 지울 수 없게 하고, 누가 언제 무엇을 했는지 추적할 수 있을 것
| 3 | 학원 운영 프로그램을 본원·지점 어디서나 동일하게 쓸 수 있을 것
| 4 | 지점 인터넷 회선이 끊겨도 접수·수업이 멈추지 않을 것
| 5 | 장비나 케이블 한 개가 죽어도 접수·수업이 멈추지 않을 것
| 6 | 신규 강사 노트북과 수업용 태블릿이 별도 설정 없이 붙을 것 (유선·무선 모두)
| 7 | 학생·학부모 Wi-Fi와 열람실 개방 포트가 내부 자료에 닿지 않을 것
| 8 | 지점이 1곳 더 늘어도 같은 방식으로 확장될 것
