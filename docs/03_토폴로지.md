# 토폴로지
## 구조적 환경을 고려한 결정 사항
### 층간 구간은 광케이블 4층에서 11층 거리라 100m 안으로 해결되지 않을 가능성 농후

### 코어 스위치와 서버를 어디다 둘것이냐. 4층.
11층은 꼭대기 층이라 여름에 매우 더움. 그리고 메인 공간이 4층. (수업, 결제, 부모님 상담)
온도와 장애 영향 범위를 물리 보안보다 우선했고, 물리 보안은 잠금 랙과 위치 선정으로 보완했다



## 비용 검토
### 코어 스위치를 한 개 두냐 두 개 두냐. 최소 구성은 L3 한대. 안정성을 생각하면 두개. 하지만 가격이 두배. 고객님의 결정.
    우선 두대 설치를 생각하고 구성함.

### AP는 각 층마다 두대
AP 중 한대가 EWC(Embedded Wireless Controller) - WLC 역할을 겸하는 AP
소규모 학원의 구조에 WLC는 비용적으로 부담.
**PT에는 EWC 기능이 없어 WLC 사용. 실제 설계 도입에선 EWC 사용**

### POE 스위치 대신 POE 인젝터 사용
POE 스위치는 일반 스위치에 비해 몇십만원 비쌈.
POE 인젝터를 사용하면 몇만원 안으로 해결 가능
**PT에서는 POE 스위치 사용. 실제 설계 도입에선 POE 인젝터 사용**

### 실제 도입에선 가격이 CISCO보다 합리적인 네트워크 장비 사용
CISCO로 맞출 이유 없음. 가격 합리성을 우선으로.
